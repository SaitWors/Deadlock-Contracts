# Проверка первого визита

Этот лист нужен для приёмки выпуска из [плана развития](ROADMAP_RU.md). Он описывает проверки, а не утверждает, что ручная приёмка уже выполнена.

## До выкладки

В GitHub открыть проверки PR и убедиться, что обязательные задачи завершились успешно. Из frontend-задачи скачать артефакт `bureau-design-preview`, распаковать и открыть `first-visit.html` локально. В нём настоящие компоненты с демонстрационными ответами кошелька: это не production-баланс. Если нужен свежий артефакт, из каталога `frontend` выполнить:

```bash
pnpm build
node tests/build-bureau-layout.mjs ../.qa/bureau-layout
```

Проверить ширины 320, 390, 768 и 1440 px, русский и английский язык. Самый важный сценарий — небольшой телефон с длинными подписями. Проверить фокус клавишей Tab, отправку кнопкой Enter/Space и читаемость при увеличении масштаба. Нельзя считать DOM-тесты доказательством отсутствия визуальных наложений.

## Учебный пример

- [ ] На главной заметно действие «Попробовать без входа»; Steam-вход и пример подписания по-прежнему доступны.
- [ ] На `#try` сразу понятно, что жетоны не начисляются и результат не переносится в аккаунт.
- [ ] Нельзя повторно выбрать символ или отправить неполный ответ. Удаление последнего символа работает.
- [ ] Ответ Компас → Руки → Хамелеон → Документы даёт **2 на месте и 1 на другой позиции**.
- [ ] Ответ Компас → Часы → Руки → Документы завершает пример. Показан результат без вымышленного баланса.
- [ ] После шести неверных ответов есть разбор; его можно открыть и раньше. Повтор начинает чистый пример.
- [ ] Кнопка входа ведёт к существующей Steam-авторизации. Учебный экран не отправляет запросов начисления, покупки или создания настоящего раунда.
- [ ] «На главную», переход к контрактам и кнопка «Назад» браузера не оставляют пустой экран.

## После Steam-входа

Эту часть проверять в тестовом экземпляре с собственным тестовым аккаунтом. Не передавать другому человеку аккаунт Steam или Overwolf. Офлайн-страница покрывает состояния интерфейса, но не проверяет реальный вход и связь с сервером.

| Состояние | Ожидаемое поведение |
| --- | --- |
| Кошелёк загружается | Нет вымышленного нулевого баланса; коллекция и бюро доступны |
| Запрос завершился ошибкой | Видны объяснение и повтор; после успешного повтора показаны данные |
| Есть незавершённый шифр | «Продолжить шифр» открывает архив с существующим раундом |
| На неделю остались задания | «Разобрать шифр» открывает архив; награда и лимит совпадают с сервером |
| Все задания недели выполнены | Предлагается коллекция, показано время обновления; новая награда не обещается |
| Вернулись домой после начисления | Баланс и следующий шаг обновились |
| Открыли прямую ссылку на другой раздел | Раздел и существующее вступление работают по прежним правилам |
