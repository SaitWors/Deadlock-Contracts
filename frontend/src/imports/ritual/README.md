# Ritual visual assets

- `valveoracle-semibold.woff2`: copied unchanged from the user's supplied `deadlock-contracts-docker (2)(2).zip`, `public/fonts/valveoracle-semibold.woff2`. Fontconfig reports Cyrillic and Latin coverage. Used for display text and numerals.
- `inter-*.woff2`: existing local Inter files from `app/static/assets/fonts/` at upstream `f8ceac6`, copied unchanged for bundling. Used for interface labels and body text.
- `contract-seal.avif`: original decorative artwork generated for this correction with the built-in ImageGen tool, then converted to AVIF with its alpha preserved. The selected prompt requested three thin concentric circles, a pentagram, a central eye and radial ticks in matte sage, on transparency, without text, gradients, glow or particles. The earlier detailed variant was discarded.

The old city montage and Jost import are no longer part of the main Ritual presentation. This folder contains no competitor assets.
