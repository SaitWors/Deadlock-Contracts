# Deadlock Contracts Companion 0.5.2-alpha.6

Исправленный QA candidate на базе последней рабочей alpha 5.

## Главное

- Данные GEP/heartbeat остаются только диагностическим сигналом: итог контракта и XP выдаёт исключительно сервер по подтверждённому provider match.
- Terminal `match_ended` не вытесняется обычными heartbeat при переполнении offline-очереди; повторная доставка идемпотентна и использует bounded exponential backoff.
- При любой смене Match ID очищается состояние прошлого матча, включая outcome, team и clock.
- Диагностический лог редактирует roster/Steam identifiers; overlay получает компактный snapshot без сотен log-записей.
- Реклама создаётся только в Desktop HQ после свежего подтверждённого safe-state; при неизвестном/устаревшем состоянии действует fail-closed.
- Динамический пользовательский текст, ошибки, названия и описания контрактов доступны на русском и английском.

Alpha 6 не подменяет alpha 5: хэш исходной рабочей базы сохранён в `COMPANION_SOURCE_PROVENANCE.json`.
