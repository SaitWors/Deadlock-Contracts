# Локальная проверка Contract Relay

На машине с контейнером Ingest запустите команду с доступом к его Docker Engine.

```bash
python3 scripts/contract_relay_status.py
```

По умолчанию скрипт смотрит контейнер `contract-relay-ingest`. Другое имя можно передать через `--container`. Скрипт читает состояние Docker и до 300 последних строк журнала текущего запуска. В JSON попадают только состояние контейнера, время и счётчики распознанных событий. Для скрипта достаточно Python 3.11+ и Docker CLI.

| Поле | Как читать |
| --- | --- |
| `container_status` | Состояние из Docker, например `running` или `exited`. Для `exited` и `dead` выводится `container_exit_code`. `missing` означает, что Docker не нашёл контейнер. |
| `gc_logs` | `recent` — есть свежая запись GC. `stale` — последняя запись старше порога. `missing` — в прочитанных строках текущего запуска нет записи GC. `unavailable` — состояние или журнал не удалось прочитать. |
| `last_metadata_quota_signal_at` | Последняя запись о том, что Ingest пропустил аккаунт с исчерпанной квотой метаданных матчей или получил ограничение от Steam GC. |
| `last_history_rate_limit_at` | Последняя запись об ограничении запросов истории матчей друзей. |
| `last_salt_upload` | Время отчёта Ingest о проходе, в котором удалось отправить хотя бы одну запись с метаданными для загрузки повтора, и число таких записей за этот проход. |

Код `0` означает, что контейнер запущен и журнал GC содержит свежую запись. Сообщение об исчерпанной квоте тоже считается записью об активности. Код `1` означает, что контейнер не запущен, либо в журнале нет свежей записи GC. Код `2` означает, что чтение данных Docker завершилось ошибкой или аргументы команды недопустимы.

Порог свежести по умолчанию — 90 минут. В изученной версии Ingest между проходами GC ждёт 30 минут после завершения прохода. Если режим запуска отличается, задайте свой порог через `--stale-after-minutes`. [Исходный код GC Ingest](https://github.com/deadlock-api/deadlock-api-ingest/blob/d8d51587253c25e09368010d959e7618e0f7a345/src/gc/mod.rs)

По этим записям нельзя определить текущий остаток квоты, время её восстановления или время появления матча в Deadlock API. Успешная отправка метаданных и проверка контракта происходят на разных этапах. Скрипт запускает только `docker container inspect` и `docker container logs`.
