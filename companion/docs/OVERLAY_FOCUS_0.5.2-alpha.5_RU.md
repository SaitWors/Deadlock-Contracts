# Live Focus Overlay — 0.5.2-alpha.5

## Поведение

- Только одна активная метрика из 1–3 выбранных контрактов текущего строго определённого режима.
- Переключение activity focus по-прежнему имеет 3-секундное окно стабилизации: случайный единичный event не дёргает плашку.
- Значения live — только `PROVISIONAL`; закрытие, XP и итог остаются на сервере.
- Нажатие фактического hotkey (по умолчанию `Ctrl+Shift+C`) показывает плашку. Повторное нажатие скрывает её. Без повторного нажатия окно минимизируется через 6.5 секунды.
- Вся плашка input-pass-through, ресайзится через Desktop S/M/L, удерживается в границах игры и уходит вниз при наведении, чтобы игрок не терял доступ к game UI.

## Визуальные изменения

- скруглённый 18px contract frame с латунно-мятной палитрой;
- animated progress fill и короткий highlight только при изменении живого значения;
- мягкое появление при смене цели;
- короткий burst при `TARGET MET · PROVISIONAL` — это не «награда», а лишь визуальная обратная связь;
- `prefers-reduced-motion` отключает motion.

## Ручная проверка

Проверить на реальном Deadlock: hotkey, повторное скрытие, авто-скрытие, unassigned binding, hover dodge, fullscreen/windowed/Alt+Tab и отсутствие перекрытия нужных HUD-элементов.
