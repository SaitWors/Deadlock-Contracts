## Существенные сценарии

- Два одновременных запроса ежедневного пака, одинаковые и разные ключи запроса.
- Повтор с другим ключом, потерянный ответ и переход через полночь: исходная квитанция сохраняется; новый ключ получает только новую дневную выдачу.
- Гонка между начальным чтением и `begin`: повтор не выпускает ещё один комплект.
- Пустой или неполный пул не расходует ежедневную выдачу; REAL и SANDBOX не дают два ежедневных пака.
- Историческая математика паков/возвратов/инвентаря сохранена в нижележащих сервисах, а закрытые HTTP-действия отвечают 410. Выпуск валюты отключён.
- Отмена и сетевые ошибки подписания, изменившийся выбор, повторное нажатие, неподтверждённый ответ сервера, завершение/ошибка/зависание видео, пропуск и уменьшенное движение.
- Ограничение ожидания ежедневных GET/POST, восстановление по исходному ключу, смена аккаунта и unmount.
- Административные черновики карточек, проверка и настройка паков остаются доступны; каталог и Арена в пользовательских сценариях отсутствуют.

## Что не заявляется проверенным

Локальный Docker daemon отсутствует. Проверка production Docker build и PostgreSQL должна пройти в GitHub Actions; локальные API-тесты использовали SQLite. Конкурентные тесты используют отдельные соединения к файловой SQLite; на PostgreSQL дополнительно применяется существующая блокировка пользователя FOR UPDATE.

Облачный браузер не получил доступ к порту контейнера; file-навигация запрещена его политикой. Поэтому визуальная приёмка новой сборки, настоящая декодировка видео, мобильная вёрстка и нативное удержание фокуса не заявляются пройденными. Также не проверялись настоящий Steam-вход и Overwolf внутри игры.

Исторические тесты закрытых операций обновлены под новую модель; пропуски для обхода регрессии не добавлялись.
