# PR42: соответствие анимациям и обнаружение сайта

База: main `17729916a5394e01d58033455d7f961452d4ec4b` после PR41.
Референс: переданный пользователем `pack-open-test (1).zip`.

## Обнаруженные расхождения

| Часть | Было | Изменено |
| --- | --- | --- |
| Упаковка | Полоса и конверт исчезали за 550 мс | Разрез, последовательное сгибание сегментов полосы, отделение верха, падение обёртки, появление веера и переход к стопке; 3,2 с |
| Завершение | Только короткий таймер | Событие завершения всей сцены; резервный таймер 3,6 с, если событие не пришло |
| Веер | Отсутствовал | До четырёх рубашек по фактическому количеству предметов; не показывает выдуманные награды |
| Покрытие карточки | Один градиент | Отдельные цветовые, отражающие и световые слои, foil/holo и усиленные покрытия SS/SSS |
| Сенсорный ввод | Блик реагировал только на мышь | Наклон и блик при касании, в том числе в коллекции и итогах; вертикальный жест оставлен прокрутке |
| SEO-диагностика | Локальные проверки и ручные curl-команды | Воспроизводимый read-only аудит опубликованных robots, sitemap и всех страниц |
| Ответы о продукте | Общее описание | RU/EN-ответы о сайте и моде, выборе целей и гостевых возможностях; видны без JavaScript |

Оформление упаковки и карточек остаётся Deadlock Contracts. В архивном примере
Pack Opening Animation часть HTML повреждена, а графика берётся с внешних S3 URL.
В CoolCardAnimation-p1 лежит сторонний проект pokemon-cards-css с GPLv3.
В PR используется собственная реализация визуальной последовательности и слоёв:
исходники, текстуры, Pokémon-изображения и внешние зависимости из архивных
демонстраций не включены в приложение. Это не побайтовый перенос демо.

## Сохранённые свойства

- Серверная квитанция определяет награды; показ не выполняет повторную покупку.
- Порядок и количество карточек, отметки дублей и тестовой выдачи сохранены.
- Работают клавиатура, переворот, свайпы и асинхронное сохранение избранного.
- Skip, Escape, закрытие, новая квитанция и размонтирование отменяют старую сцену.
- Reduced motion сразу показывает итог, отключает наклон и блики.
- Исходные изображения и подписи не перекрываются голографией: эффекты внутри окна арта.

## Как воспроизвести визуальную проверку

```bash
cd frontend
pnpm build
node tests/build-card-layout.mjs ../.qa/pack-layout --packs
```

Открыть полученный index.html локально обычным браузером. Стенд использует
настоящие компоненты, production CSS и подставные данные; сетевые обращения
замкнуты внутри fixture. Проверить 320/390/1440 px, 0/1/9 карточек, все ранги,
открытие, пропуск, повтор, клавиатуру, свайпы, избранное и reduced motion.

Автоматические проверки покрывают полный переход сцены, игнорирование завершений
дочерних анимаций, touch с переворотом и без него, отмену таймеров и прежние
сценарии покупок/квитанций. Визуальная сверка в браузере этой сессии заблокирована
политикой среды на локальные URL. Соответствие по внешнему виду остаётся пунктом
ручной приёмки: нельзя считать его подтверждённым по одним DOM-тестам.

CSS увеличился примерно на 4,3 KB без сжатия. Лимит CSS изменён с 325 на 330 KB
для этих слоёв и фаз; остальные лимиты, включая стартовый JavaScript, сохранены.
