# Live Focus Overlay — 0.5.2-alpha.3

Сохраняет single-focus overlay из alpha.2:

- только Active Case текущего строго определённого режима;
- одна активная метрика на экране;
- 3-секундное окно переключения между damage / assist / kill и другими событиями;
- плавный provisional progress;
- translucent presentation;
- hover dodge вниз через input-pass-through window;
- unknown mode fail-closed.

Alpha.3 не меняет settlement authority: live overlay остаётся provisional.
