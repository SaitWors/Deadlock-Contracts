# PR45 · City Never Sleeps

Обновление подготовлено поверх `main` с уже объединённым PR44.5 — `3f45f61494f072538530e262a2ba89c765a29559`. Название релиза — PR45; номер pull request на GitHub назначается отдельно, поскольку #45 занят PR44.5.

## Дизайн

Референс: [официальная страница City Never Sleeps](https://www.playdeadlock.com/cityneversleeps), изученная 2–4 октября 2026. Проверены длинная настольная страница, мобильная версия, районы города, плакаты героев, панели интерфейса и анимации. В Contracts перенесены угольные фоны, тёплая бумага, оранжевые наклейки, крупная плакатная типографика, двойные линейки и рамки иллюстраций. Навигация и плотные таблицы сохраняют читаемый шрифт интерфейса.

Один визуальный язык используется до и после входа, в архиве, коллекции, конвертах, мастерской, профиле, бюро, уведомлениях, голосовании, админке, подписании, Companion, юридических страницах, reviewer и серверных страницах без JavaScript. Стили обновлены в существующих владельцах компонентов. Светлая, тёмная, ультрачёрная, кастомная и системная темы, RU/EN и сохранённые настройки остались совместимыми.

Прежний робот-маскот сохранён в трёх естественных позах. Дыхание, смена поз, подъём карточек и подтверждающая печать учитывают reduced motion. Печать успешного подписания появляется после ответа сервера. Вступительная панель и её кнопки также используют новые цвета.

Jost и Ruslan Display поставляются локально с OFL; Cormorant оставлен для подписи. Три городские сцены и шесть плакатов Valve поставляются локально, без загрузки с внешнего CDN при работе приложения. Источники и контрольные суммы: [city-artwork.json](city-artwork.json), [манифест плакатов](../../../app/data/archive/city-never-sleeps/manifest.json), [THIRD_PARTY_NOTICES](../../../THIRD_PARTY_NOTICES.md). Имена героев сопоставлены с надписями на изображениях: некоторые имена файлов официального CDN не соответствуют содержимому.

Карточки добавляются при запуске через детерминированные идентификаторы и insert-only seed. Повторный запуск сохраняет правки, заменённые изображения и архивирование администратором. Существующие коллекции, балансы, покупки, версии конвертов и вероятности не меняются. Полные официальные плакаты показываются без обрезания; изменённые куратором изображения и кадрирование продолжают использовать обычные настройки. Дополнительный API-признак `release_poster` вычисляется по фактическим байтам изображения.

Публичный маршрут иллюстраций разрешает только шесть известных ключей. Доступ к пользовательским и приватным изображениям сохраняет авторизацию. Новые игровые способности и числовые ID героев не добавлялись.

## Совместимость с PR44.5

Сохранены кампания голосования, кэш источников, worker, миграция 0020, роли и TOTP. Вкладка голосования появляется при активной кампании; при её отсутствии доступны прежние 14 разделов. В активном состоянии проверены все 15 разделов аккаунта и 17 вкладок админки, включая мобильный выбор раздела. Управление кампаниями проходит через существующие серверные обработчики.

Из проекта удалены 52 неиспользуемых файла старых шрифтов и фонов, всего около 2,62 МБ, и около 40 КБ устаревших CSS-правил. Исторические материалы, используемые подписи, маскот и пользовательские оформления сохранены. Лимиты размера сборки остаются такими же, как в PR44.5.

В браузерных проходах нет ошибок JavaScript, неудачных запросов, сломанных изображений и горизонтального переполнения документа. Через реальный локальный API подтверждены покупка новой карточки со списанием 20 жетонов, возврат из подписания, успешное подписание с серверной квитанцией, создание/активация/скрытие/повторная активация/завершение кампании. Исправлена упаковка Docker: самостоятельные документы получают собственные шрифты и городские фоны после очистки Vite assets. Проверка SEO в образе проверяет и транзитивные CSS-ссылки на файлы. Подмена изображения куратором и произвольные серые кастомные акценты имеют отдельные регрессионные тесты.

Браузерные данные, включая снимки голосования, созданы только в одноразовой QA-базе. Настоящий вход в Steam и запуск Overwolf в Windows с живой игрой в Linux-среде не выполнялись. Docker и PostgreSQL проверяются обязательными заданиями CI pull request.
