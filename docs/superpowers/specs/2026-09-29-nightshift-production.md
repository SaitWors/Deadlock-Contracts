# Nightshift: перенос утверждённого дизайна

Цель: перенести оформление прототипа V3 в существующий React-интерфейс, заменить T-позу тремя естественными позами того же маскота, обеспечить видимое переключение RU/EN до и после входа и сохранить рабочие функции.

Основа: main `309d72e3f8427d6cc0c82060901bfacb3a38c4d8` (PR42). Реальные API, CSRF, авторизация Steam, ограничения ролей, 16 разделов админки и бизнес-обработчики сохраняются. Демонстрационные данные из прототипа в рабочий сайт не переносятся.

Оформление: светлая, тёмная, ультрачёрная, авторская и системная темы; настройка акцента авторской темы и радиуса 12–28 px; локальное сохранение; системная тема следует ОС. Язык использует существующий LanguageProvider и публичные адреса /ru/ и /en/; явный выбор сохраняется для аккаунта после Steam.

Маскот: неизменные костюм, маска с одним зелёным глазом, шляпа и эмблема. Позы: спокойная, приветствие с касанием шляпы, изучение папки. Плавное дыхание, переходы между позами и реакция на наведение. Системное уменьшение движения и ручное отключение имеют приоритет. Это анимированные 2D-иллюстрации, не 3D-модель.

Приёмка: все прежние тесты, тесты темы/языка/движения, проход по 16 вкладкам админки, мобильные ширины 360/390 и desktop 1440, сборка Vite и проверка TypeScript. Загрузка в отдельную ветку GitHub с PR; production-развёртывание в эту задачу не входит.
