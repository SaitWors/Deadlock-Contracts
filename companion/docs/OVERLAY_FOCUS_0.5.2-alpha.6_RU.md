# Live Focus Overlay — 0.5.2-alpha.6

- Показывает только выбранный контракт активного серверного дела текущего режима.
- Локальные значения всегда обозначены как provisional и не закрывают контракт.
- Горячая клавиша берётся из Overwolf Settings; повторное нажатие скрывает overlay.
- Автоскрытие — 6,5 секунды; окно ограничено границами игры и пропускает игровой ввод.
- При hover плашка меняет безопасную позицию; обязательна ручная проверка на всей DPI/resolution матрице.
