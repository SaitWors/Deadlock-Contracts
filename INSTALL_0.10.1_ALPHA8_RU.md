# Deadlock Contracts 0.10.1-alpha.8 — установка

Web/backend release: `0.10.1-alpha.8`.

## Companion

Каноническая версия:
`0.5.2-alpha.5`.

Overwolf manifest:
`0.5.2.5`.

Recovery build `0.5.0-alpha.3` не является текущей
public-версией.

До подключения официального `COMPANION_DOWNLOAD_URL`
тестерам выдаётся только проверенный build
`0.5.2-alpha.5`.

После установки:

1. войдите через Steam;
2. создайте pairing code;
3. введите код в Companion;
4. проверьте paired/online status;
5. запустите Deadlock;
6. проверьте mode и Match ID.

Финальный verdict и XP определяет сервер.
