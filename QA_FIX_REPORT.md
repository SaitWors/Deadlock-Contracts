# Overwolf QA remediation report

Candidate `0.5.2-alpha.21` uses Overwolf manifest version `0.5.2.21`. The original QA report covered manifest `0.5.2.8`. All 66 files in the supplied `alpha.20` OPK matched the local QA commits. The supplied ZIP had another identical copy of those 66 files under a nested application folder. The new OPK has a single application root and leaves the browser preview fixture in the source archive. The original DOCX, banner and linked 9.9-second `hotkeys.mp4` were reviewed. The clip shows both the Overwolf Overlay & Hotkeys settings and an extra blank browser window after clicking Hotkey.

On 20 November 2026 the public site reported web `0.10.1-alpha.12`, minimum Companion `0.5.2-alpha.18`, public alpha access and ads disabled. `GET /pair` and `GET /companion/uninstall` responded with 404. Unauthenticated POSTs without a valid payload identified the legacy code routes (`start` 403, `claim` 422) and the missing browser routes (`link/start` and `link/claim` both 404). The staged revision implements all four routes plus approval and cancellation. [Public status](https://deadlock-contracts.online/api/status)

## Runtime evidence

Windows had two connected 1920×1080 displays and Overwolf Developers `0.317.0.16`. Overwolf opened its existing unpacked `alpha.20`. It rejected installation of the local `alpha.21` QA OPK as an unverified version. The local PostgreSQL HTTP smoke used a development account and verified browser approval, concurrent claim, an `alpha.20` credential upgrading to `alpha.21`, three-contract lock and retry, bootstrap and revocation. Real Steam authentication, live ad creative rendering and native uninstall acceptance remain release gates.
