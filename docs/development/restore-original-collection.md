# Исправление коллекции после PR #50

PR #50 ошибочно публиковал отдельные 110 геометрических карточек, выдавал из них стартовый состав и требовал отдельный художественный допуск для прежних карт. Исправление прекращает эту публикацию и подключает арену к существующей коллекции.

## Что меняется

- При запуске добавляются только боевые определения, без новых карточек или изображений. Для прежних опубликованных и архивных карт поддерживаемых героев боевые правила выбираются по герою и рангу. Явная привязка к версии, отзыв допуска и запрет определения имеют приоритет. Для EX по-прежнему необходим явный допуск.
- В составе и бою используются принадлежащие игроку физические экземпляры, их прежние изображения и выбранная EX. Изображения архивных карт соперника доступны только участникам соответствующего боя.
- Стартовый состав использует существующие опубликованные F-карты Abrams, Bebop, Dynamo, Haze, Ivy и Seven. Если хотя бы одного оригинального рисунка нет, выдача недоступна; интерфейс предлагает собрать состав из своей коллекции. Уже использованное право на стартовый набор не выдаётся повторно.
- Коллекционная доступность отделена от боевой: паки могут содержать опубликованные оригинальные карты любого известного архиву героя. Арена поддерживает двенадцать героев с существующими правилами. Шесть постеров City Never Sleeps остаются коллекционными: правила для Nurse Harrow, Rat King, Solomon, Deadman Danny, Baba и Violet этим исправлением не добавляются.
- Неполный пул всех девяти рангов не создаёт новый пак и блокирует покупку существующего непригодного пула до списания монет или изменения гарантий.

## Миграция и сохранность данных

`0023_restore_original_collection` меняет только статус `PUBLISHED → ARCHIVED` у неизменённых карточек ошибочного выпуска. Проверяются стабильный ID, все исходные метаданные, временные метки, SHA-256 настоящих байтов, исходное боевое определение и отсутствие действий куратора. Изменённые или явно отмодерированные записи сохраняются. Та же идемпотентная проверка выполняется при запуске.

Карточки, изображения и экземпляры не удаляются и не заменяются. Выданные геометрические экземпляры остаются у владельцев и доступны для боя. Балансы, REAL/SANDBOX, себестоимость, покупки, квитанции, избранное, резервы и снимки прошлых/активных боёв сохраняются. Исправление не подменяет купленную карту другим ID.

Для двух неизменённых активных системных паков PR #50 добавляется ревизия 2 с оригинальным пулом, если он полон. Ревизия 1, раскрытия и квитанции сохраняются. Изменённые, приостановленные или имеющие иную историю паки автоматически не переписываются. Повтор оплаченного запроса возвращает прежнюю квитанцию.

Downgrade `0023 → 0022` не публикует геометрические карточки обратно. Возврат старого приложения снова включит его ошибочный seed, поэтому для восстановления следует применять процедуру backup/restore проекта.

## Развёртывание

1. Сделать обычную резервную копию базы и остановить web/worker на время миграции.
2. Развернуть новую версию и выполнить `python -m app.migrate`.
3. Проверить `python -m alembic current --check-heads` (head `0023`) и `python -m alembic check`.
4. Запустить web/worker. Проверить каталог без фильтров, прежний инвентарь, квитанцию покупки и путь «коллекция → состав → бой» с исходными рисунками. При неполном каталоге проверить объяснение недоступности старта/пака и неизменность баланса после отклонённой покупки.

Исправление проверено на изолированных SQLite/PostgreSQL и через настоящие HTTP-маршруты: исходные WebP сравниваются побайтно и декодируются на этапах каталога, инвентаря и боя. Состояние конкретной production-базы этим PR не обследовано; если прежние изображения были изменены вне кода PR #50, их восстановление требует проверки базы и резервной копии.
